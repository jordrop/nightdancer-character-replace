# 测试门（Stage 5）

> 目的：在批量前，用最小成本验证“角色一致性 + 场景氛围 + 道具不出错”。

## 测试项（按顺序，任一项不过不进入批量）
1. 角色锚点 ×4：同一角色出一张三视图（3 积分/张）；
2. 场景 ×2：S1 灰岭 / S3 无归原 各一张（3 积分/张）；
3. 测试仍帧：C1+C4 在 S3，铜铃可见（1 张，3 积分）；
4. 测试视频：U19 或 U20 一个 15s（推荐 seedance2.0 720p = 120 分；2.5 480p = 180 分）；
5. 人工验收：人数、脸、围巾、铜铃、泥水方向、无文字水印。
