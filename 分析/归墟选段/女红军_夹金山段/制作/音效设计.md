# 音效设计（15×20s）

> 与配音表时间轴对齐；对白为主体，环境低 18–24dB；音乐在钩子处顶起。

| 单元 | 音效/环境/音乐 |
|---|---|
| N01 | 会议室底噪、纸张翻动、电报滴答、油灯轻爆；低频鼓点 40-60Hz；对白 -6dB，环境 -24dB |
| N02 | 夜行脚步、压低口令、远处零星枪声、电报尾音；低频铺底；对白 -6dB |
| N03 | 山口风雪、火塘噼啪、老爷爷咳嗽；歌谣混响略大；对白 -8dB |
| N04 | 火塘、风雪、讲述停顿处的低频 drone；结尾心跳 60BPM；对白 -6dB |
| N05 | 雪崩远鸣 30-50Hz、风、呼吸；弦乐渐入；对白 -6dB |
| N06 | 火塘、翻纸/铅笔、风雪；强调“三十多公里/九点到三点”时压环境；对白 -5dB |
| N07 | 锅勺碰锅、倒汤、吸气/呼气、短促笑；火塘暖底噪；对白 -6dB |
| N08 | 军号、口令、旗帜猎猎、马蹄、踏雪；鼓点加快；口号 -4dB |
| N09 | 强风、雪粒打衣、急促呼吸、心跳；滑坠时短促高频；对白 -6dB |
| N10 | 风、呼吸、衣物摩擦；低频虚弱感；对白 -7dB |
| N11 | 碗碰、扒雪、嚼雪、轻笑；后半段雪崩前静一拍；对白 -6dB |
| N12 | 雪崩巨响 20-80Hz、骡蹄、风压、喘息；音乐低频重击；对白 -5dB |
| N13 | 快板竹响、山歌混响、风雪；鼓点振作；快板/山歌 -3dB |
| N14 | 担架吱呀、拖步、喘息、远处喊话（混响大）；弦乐顶起；对白 -5dB |
| N15 | 风停后的静、冰碴、笑声、滑雪；弦乐收束；旁白 -6dB |
