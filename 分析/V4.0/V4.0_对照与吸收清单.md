### 2.2 可吸收增量（按优先级）

| 优先级 | V4.0 内容 | 为什么值得吸收 | 落地方式 |
|---|---|---|---|
| **P0** | **15s 内部时间引擎（标准 5×3.0s）** | 我们每单元只有"整段 15s 一个 prompt"，没有内部时间结构；AI 容易在 15s 内乱跳 | 时间线每单元加 `v4.beats`（0–3/3–6/6–9/9–12/12–15s，每段：画面/动作/镜头/声音） |
| **P0** | **三画面锚点（开场/中间关键/结尾）** | 直接对应"关键帧分镜"：每单元 3 张锚点图；避免 AI 生成时丢失结尾状态 | 加 `v4.anchors{open,mid,end}`，可作关键帧生成清单 |
| **P0** | **镜头预算/单镜复杂度** | 与导演规则景别节奏配合，防 AI 单镜过载（转身+跑步+说话+环绕一起） | 加 `v4.budget{shots, complexity}`；NORMAL 3–5 镜、ACTION 5–6 镜 |
| **P1** | **连续状态锁（湿/泥/伤/人数/道具）** | 《无归原》减员、陷泥、包扎，最容易"下一镜自动恢复" | 加 `v4.state_lock[]` + `v4.continuity{}`（地点/天气/人数/光色/湿衣/伤/道具） |
| **P1** | **下一段续接锚点字段** | 32 单元连续生成，必须承接上一段最后状态 | `v4.continuity` 复用其字段（地点/天气/位置朝向/动作表情/衣服受伤/主光色温照度/镜头/悬念） |
| **P1** | **12 项 Hard Gate 自检** | 可直接改造成我们的"单元验收表"（去掉台词项，换成"无对白/字幕"） | 写入 `文档/16` §9 或新建验收表 |
| **P2** | 微表演"抽象→可见动作"清单 | 对反应镜（阿荞/顾青）特别有用 | 并入角色/关键帧提示词模板 |
| **P2** | 镜头立场（一段只选一个主要立场） | 与导演规则重叠，但"立场"提法更简洁 | 并入导演规则 §2 接口 |
| **P2** | 环境声优先来自画面、不默认 BGM | 与无归原"无对白、纯音效"一致 | 采纳 |
| **P2** | 高危反例（色温失忆/锚点镜像/状态失忆） | 作为负面约束与验收检查 | 直接并入自检清单 |

### 2.3 不吸收/冲突

| V4.0 | 处理 |
|---|---|
| 工业科幻关键词映射（6500K/暗红 620nm/冰蓝 470nm/护盾/能量） | 同 V1000：**必须改写实灾难版**（暴雪/沼泽/篝火/灯火已写在 `文档/16` §9） |
| 台词预算 / 声音锁 | 无归原**无对白**，保留字段备用；环境声规则可采纳 |
| 系统 UI / 都市穿越 / 三人恋爱 / PHONE / ONE-TAKE | 本项目不用，留作未来模板 |
| 800–1400 字自然语言"生产模式" | 我们已有"四段式 + seedance_prompt"结构，不强制字数；可参考其"完整版 prompt"组织顺序 |
| V1000 技术脚本模式（15.3） | 与 `文档/16` §9 重复，不重复实现 |
| 动漫短剧语气（轻喜剧/吐槽/甜蜜） | 与归墟写实灾难基调不符，只取结构不取内容 |

## 5. 结论

- **V4.0 的真正价值**：不是它的 V1000 参数（我们已有），而是 **15s 内部时间结构（5×3s）+ 三画面锚点 + 连续状态锁 + 镜头预算/12 项 Hard Gate + 微表演"可见化"**；
- **不吸收**：动漫短剧语气、工业科幻映射、台词/UI/恋爱/PHONE 模块；
- 与现有体系的分工：**V4.0 管"15s 内怎么排段"，导演规则管"机位/景别/轴线"，V1000 管"光照/音效参数"，schema 管"执行"**。
