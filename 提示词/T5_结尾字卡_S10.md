## 正向提示词（可直接贴 CLI）

```
【任务】把参考图1（片尾白底字卡）中的两人替换为参考图2、3中的目标人物，其余画面不变。
【人物】左侧男性保留深蓝西装、白衬衫、手提纸袋的造型，身高与肩宽按参考图2调整；右侧女性保留黑色短夹克、白色 T 恤、深色短裙的造型，发型按参考图3（中长直发、被风轻微吹起）；两人并肩站立、身体略微侧向对方、没有肢体接触；保持原图全身站姿与比例。
【风格】2D 赛璐璐动画：平涂色块、清晰黑色线稿、硬边阴影；白色/浅蓝渐变背景干净平整，无照片质感。
【构图】严格保持原构图：两人在画面中的位置与大小、脚部位置与间距、四周白色边框宽度、底部字幕区位置均不变。
【保留】字幕「2人別々」区不动；原水印区不动；背景渐变不变。
【禁止】新增道具或文字；改变站位间距；改变服装风格；把人画成正面大头；多余手指；真实照片质感；重新构图。
```

## 负向提示词

```
真实照片、3D 渲染、大头特写、改变站位、换掉西装或夹克、新增道具、文字改动、背景出现纹理、边框消失、字幕改动、水印重绘、重新构图、多余手指
```

## 建议参数

```powershell
dreamina image2image --images "<S10 源帧>" "<目标人物全身参考>" `
  --prompt "<上方正向提示词>" --model_version 5.0 --resolution_type 2k --ratio 16:9 --generate_num 2 --poll 120
```

## 验收点

- 两人都是全身、脚部完整、间距不变
- 男主西装+纸袋、女主黑夹克+白 T+短裙的造型不变
- 白色边框、「2人別々」字幕区不变
- 脸部虽小，但发型/体型能认出是目标人物
