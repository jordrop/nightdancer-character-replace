# 提示词 · 通用风格后缀

> 五张替换帧共用的风格/画质描述。每帧提示词里已经内联，这里是单独维护的版本，
> 如果发现模型"跑偏成写实"，可以把这段追加到 prompt 末尾。

## 正向（追加）

```
赛璐璐动画风格，平涂上色，清晰的黑色描边线稿（线宽 2–3px），硬边阴影（不使用渐变雾化），
有限动画质感（limited animation），柔和的环境光（按原帧光位），
画面干净无噪点，1920×1080 构图，与原图完全同构图。
```

## 负向（追加）

```
photorealistic, 3D render, CGI, photo texture, skin pores, soft airbrush, gradient shading,
depth of field, bokeh, extra person, extra fingers, deformed hands, cropped, recomposed,
altered subtitle, repainted watermark, changed background, anime screenshot with modern UI
```

## 说明

- 即梦对中文描述的理解优于英文负面词，所以正文用中文写，负向词中英混排即可。
- 若模型把 2D 画风带成"新海诚式写实光效"，把「平涂」「硬边阴影」「线稿」提到提示词最前面。
- 若模型改了构图，重点加一句「严格保持原图构图与像素级位置，不重新构图、不裁切」。
