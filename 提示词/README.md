# 提示词库 · 索引与规范

> 提示词是本项目的核心资产：要可检索、可复现、可对账（消耗了多少积分、跑出了什么结果）。
> 本目录是**主库**；方法论在 `技能/`，工作流内的提示词卡在 `_canvas` 画布里，结果在 `即梦产物/`（不入库）。

---

## 1. 目录约定

```
提示词/
├─ README.md                     ← 本文件：索引 + 规范
├─ <项目>_<镜头/用途>_<模型>_v<版本>.md    ← 单条提示词（推荐一个文件一条，或一镜一条）
├─ _通用_风格后缀.md              ← 跨项目复用的风格/负向词后缀
├─ 待跑_*.md                     ← 批量待跑清单
└─ 参考/                         ← 外部优秀案例（官方/爆款），只学结构，不直接搬
   └─ <来源>_<日期>/
      ├─ README.md              ← 来源链接、抓取日期、学到什么
      └─ prompts.md             ← 原始提示词（标注来源，勿商用转载）
```

## 2. 单条提示词文件头（必填元数据）

```markdown
---
project: 女红军
shot: 夹金山-雪崩
target: 即梦 / Seedance 2.5
model_version: seedance2.5
resolution: 480p
duration: 4s
credits: 48
created: 2026-10-19
status: tested          # draft | tested | failed | adopted
result: 即梦产物/seedance25_test_480p/seedance25_test_480p.mp4
source: 原创            # 原创 | 参考（写来源链接）
---

## 正向提示词
（可直接粘贴的完整 prompt；单行版另存 `.txt`）

## 负向/约束
（无字幕、无文字、不换装……）

## 参数与结果
- 命令：
- 提交 id：
- 消耗积分：
- 结果文件：
- 结论：可用/需重跑/淘汰

## 迭代记录
- v1：
- v2：
```

## 3. 命名规范

- `<项目>_<镜头/用途>_<模型>_v<版本>.md`，例：`女红军_夹金山雪崩_即梦Seedance2.5_v1.md`
- 批量清单：`待跑_<项目>_<批次>.md`
- 单行 prompt（喂 CLI）：同名 `.txt`
- 外部参考：`参考/<来源>_<日期>/`，例：`参考/即梦官方_canvas_f304bc2b_20261019/`

## 4. 存放位置分工

| 位置 | 放什么 | 是否入库 |
|---|---|---|
| `提示词/` | 逐帧/成品提示词、通用后缀、待跑清单、外部参考 | ✅ 入库 |
| `技能/` | 提示词体系、方法论、skill | ✅ 入库 |
| `_canvas` 画布 `vprompt` 卡 | 工作流中正在用的提示词 | ❌（画布数据 gitignore） |
| `即梦产物/` | 生成结果（图/视频） | ❌（gitignore） |
| `分析/` | 拆镜、运镜、选段分析 | ✅ 入库（大图除外） |
