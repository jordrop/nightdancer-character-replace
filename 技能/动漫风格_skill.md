# 动漫风格 Skill（本地版 · 用于人物替换生成）

> 说明：UpDream 的技能市场需要邀请制账号、即梦网页版技能无法通过 CLI 导出，所以这里落地成**项目内可执行的动漫风格规范 + 提示词模板**，生成时直接拼到 prompt 里。
> 依据：源片《NIGHT DANCER》的赛璐璐画风 + 女主设定图 + 梁文峰三视图。

## 1. 风格硬规则（每条生成都必须带）

- **2D 动画赛璐璐**：平涂色块 + 清晰黑色线稿（2–3px）+ 硬边阴影，无照片质感、无 3D 渲染、无渐变雾化。
- **比例（已按项目确认）**：**女主保持设定图的 Q 版比例（头大身小、可爱）——这是角色设定，不算错误**；男主保持成年男性比例。Q 版同样要求解剖正确：四肢完整、每只手 5 指、脚有脚踝、无多手多脚、无肢体融合。
- **解剖正确（真错误才修）**：每只手 5 指、手掌与手腕结构清晰；脚有脚踝与脚趾；四肢完整、关节自然；不穿模、不融合、不截断、不多手多脚。
- **角色一致性**：女主 = 蓝发渐变长发 + 星星发夹 + 鱼鳍耳饰 + 白色连帽衫 + 棕色百褶裙 + 白色袜套 + 棕色玛丽珍鞋 + Claude 工牌 + 蓝色鲸尾（尾巴从髋后自然伸出，不穿模）；男主 = 黑色短碎发 + 细黑框眼镜 + 瘦削脸型 + 蓝色西装 + 白衬衫 + 黑皮鞋。
- **画面保持**：原构图、机位、背景、道具、光位、烧录字幕、水印均不变；不新增人物/文字。
- **禁止清单**：Q 版化、娃娃脸配大人身、手指数量错误、多手多脚、肢体扭曲、脚部糊成块、尾巴插在腿上、衣服与身体融合、脸部比例崩坏。

## 2. 提示词模板（前缀 + 帧指令）

```
【动漫风格·硬规则】2D动画赛璐璐：平涂色块、清晰黑色线稿、硬边阴影；成年角色比例（7头身，禁止Q版/幼态/大头娃娃），每只手5指、脚部有脚踝脚趾、四肢关节自然、不穿模。
【角色】女主=蓝发渐变长发+星星发夹+鱼鳍耳饰+白色连帽衫+棕色百褶裙+白色袜套+棕色玛丽珍鞋+Claude工牌+蓝色鲸尾（髋后伸出）；男主=黑色短碎发+细黑框眼镜+瘦削脸型+蓝色西装+白衬衫+黑皮鞋。
【任务】<本帧的具体替换说明>
【保持】原构图/背景/道具/光位/字幕/水印不变；不新增人物与文字。
【禁止】Q版、幼态比例、畸形手/脚/腿、多手多脚、肢体融合、尾巴穿模、真实照片质感、重新构图。
```

## 3. 生成参数（已固化）

```powershell
dreamina image2image --images "<源帧>,<女主设定图>,<梁文峰三视图>" --prompt "<模板+帧指令>" `
  --model_version=5.0 --resolution_type=2k --ratio=16:9 --generate_num=1 --poll=240
```

- 每帧 3 积分；先 1 张，验收不过再加。
- 参考图顺序必须固定：源帧 → 女主 → 男主（模型按顺序理解参考图1/2/3）。

## 4. 验收（人形态专项）

- [ ] 头身比正常（不是 Q 版）
- [ ] 手：5 指、手指长度自然、无融合
- [ ] 脚：有脚踝、脚趾可见（近景时）
- [ ] 腿：长短与身体协调、关节位置正确
- [ ] 尾巴：只从髋后出现，不穿过裙子/腿
- [ ] 两人同框时身高比例协调（男高女矮但不悬殊）
