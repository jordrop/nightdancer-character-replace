## 2. 主模板（完整版 · 推荐）

> 依此顺序拼：任务 → 角色 → 风格 → 场景构图锁 → 动作表情锁 → 保留 → 禁止。每段缺一不可。

```
【任务】以【角色参考图】作为唯一角色视觉参考，把【源帧】中的原人物整体替换为该角色，保持源帧的构图、场景与人物姿态不变。

【角色·是谁】严格保持角色参考图的身份与外观：脸型、五官比例、发型、发色、瞳色、服装、配饰、身体比例与画风全部沿用；女主为 Q 版比例（头大身小、可爱，属角色设定；**头身比约 3–3.5 头身、腿短手脚小，同框站姿时身高约为成年男性的 1/2–2/3、头顶只到男性胸口高度，不能和成人一样高**）；男主为成年男性比例。不得继承或混入源帧原人物的脸、发型、服装或其他特征，不得重新设计角色。

【风格·怎么画】2D 动画赛璐璐：平涂色块、清晰黑色线稿（线宽与原图一致）、硬边阴影；与源帧画风统一，无照片质感、无 3D 渲染、无塑料感；保留源帧光位与色彩氛围。

【场景与构图·在哪】严格保持源帧的场景与构图：机位、景别、透视、人物在画面中的位置与大小、背景布局、道具位置、光向与色温、以及烧录的三行字幕与左上角水印的位置，全部不变。允许为贴合人物姿态做极小的取景微调，但不得改变场景地点、不得新增/删除环境元素。

【动作与表情·怎么摆】严格复刻源帧中该人物：身体姿态、重心、手臂与手部动作、腿部与脚部位置、头部朝向、表情；动作自然、关节方向正确；替换后仍保持原帧的遮挡关系（谁在前谁在后）。

【保留】源帧中未被替换的角色（路人/同事/动物/道具）保持原样；字幕文字与位置、平台水印、画面边框保持不变。

【禁止】只换头、保留原服装、改变姿态或朝向、改变构图、新增人物或文字、替换未授权角色、Q 版角色被画成写实成人、成年角色被画成 Q 版、畸形手/脚、多手多脚、肢体融合、关节反折、尾巴穿模、服装变形、真实照片质感、重新构图。
```

## 6.5 Q 版身高专项（本项目高频错误）

> 现象：Q 版角色被画成和成年角色一样高 → 与"小小一只"的设定冲突。生成时必须显式写死尺寸关系。

```
【Q版身高】女主为 Q 版幼态：头身比约 3–3.5 头身，腿部与手臂短小、手脚小；
同框站姿时身高约为成年男性的 1/2–2/3，头顶大约只到男性胸口高度；
坐姿同框时她的头比男性低约一个头。
禁止把 Q 版角色画成成人身高、成人腿长或与男性等高。
```

| 场景 | 追加写法 |
|---|---|
| 站姿同框 | `Q版女主头顶只到成年男性胸口，明显比他小一号` |
| 坐姿同框 | `Q版女主坐着时头比男性低约一个头，小小一只` |
| 站在高处（梯子/箱子） | `即使站在矮梯上，Q版女主整体仍比成年男性矮，只是位置更高` |
| 近景特写 | `不涉及身高对比，但腿与手臂仍保持Q版短小比例，不要成人长腿` |

## 6.6 人形态错误专项修复模板（只修错，不改 Q 版设定）

> 出现以下问题时，追加这一段，不要改整体设定：

```
【人形态修正】保持角色原有的 Q 版/成年比例不变，只修正解剖错误：每只手 5 指、手指长度自然、手掌与手腕结构清晰；脚有脚踝、脚掌与脚趾；四肢完整、关节方向正确、无多余肢体；尾巴只从髋后自然伸出，不穿过裙子/腿部；衣物与身体不融合；脸部五官稳定、不漂移、不崩坏。不得通过"改成写实成年比例"来修正 Q 版角色的比例。
```

| 问题 | 针对性追加 |
|---|---|
| 多指/缺指/手指融合 | `手部特写：五指分明、指甲与指节可见、手指不融合不粘连；另一只手不出现多余手指` |
| 多手多脚/肢体融合 | `全身只有两只手两条腿；手臂自然连接肩膀、腿连接髋部；两人之间不出现融合肢体` |
| 脚部糊块 | `脚穿棕色玛丽珍鞋（女主）/黑皮鞋（男主），有鞋跟、鞋面与脚踝结构，脚不糊成色块` |
| 尾巴穿模 | `蓝色鲸尾只在身后裙摆下方自然伸出，不穿过裙摆与腿部，尾巴有分节与尾鳍` |
| 换头/身份漂移 | `整张图只有一张脸是角色参考图的身份；脸型五官与参考图一致，不出现第二张脸或换脸` |

## 7. 生成参数与流程

```powershell
# 参考图顺序固定：源帧(图2/图1顺序见下) → 角色参考
dreamina image2image --images "<源帧>,<角色参考1>[,<角色参考2>]" `
  --prompt "<第2节主模板 + 第5节本帧段落>" `
  --model_version=5.0 --resolution_type=2k --ratio=16:9 --generate_num=1 --poll=240
```

- **参考图顺序**：源帧放第 1 张（当"图2 场景"），角色参考第 2 张起（"图1 是谁"）——模型按顺序理解图1/图2，提示词里明确写"参考图1是源帧、参考图2是角色"。
- 每帧先生成 1 张（3 积分），验收不过再补；不要一次生成多张浪费。
- 只做 **K04/K05/K07/K08/K09/K10/K11**（C1/C2 独占的帧）；K02/K03/K06 暂缓。

## 8. 验收清单（逐条打勾）

- [ ] 身份：只有角色参考图的脸/发型/服装，没有源帧原人物的特征残留
- [ ] 比例：女主 Q 版（头大身小）、男主成年；两者与设定一致
- [ ] 手：5 指、不融合、不多手
- [ ] 脚：脚踝+脚清晰（近景时必须）
- [ ] 腿/关节：自然弯曲、不反折、不截断
- [ ] 尾巴：从身后伸出、不穿模
- [ ] 构图：背景/机位/道具/人物位置与源帧一致（叠图偏差 ≤2%）
- [ ] 字幕/水印：文字与位置未被改动
- [ ] 未替换角色：路人/同事/狗/道具保持原样
- [ ] 画风：2D 赛璐璐、线稿+平涂+硬边阴影；无照片/3D 质感
