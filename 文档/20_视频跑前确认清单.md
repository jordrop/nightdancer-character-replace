# 视频跑前确认清单（双重确认 + 参数清单）

> 2026-10-19 用户指定：任何视频生成前，必须连续确认两次「是否真的要跑成片」；每次确认前先列出已有参数。
> 未完成两次确认，禁止调用 `multimodal2video` / `image2video` / `text2video`。

## 第一次确认：参数与方向核对

先向用户展示以下清单，并问「以上参数是否正确？是否继续进入最终确认？」：

| 项 | 内容 |
|---|---|
| 单元/用途 | 例如 U19 踏入沼泽 / 夹金山 20s 短剧测试 |
| 生成方式 | 默认 `multimodal2video`（全能参考） |
| 模型 | `seedance2.5` |
| 分辨率 / 比例 | `480p` / `16:9` |
| 时长 | 15s / 20s（2.5 支持 4–30s） |
| 首帧 | 关键帧路径（如 `KA_U19_open.png`） |
| 参考图 | 角色 C1–C4 / 场景 S1–S5 / 道具 / 关键帧（逐条列出路径） |
| 对白/声音 | 台词文本、画外音、`<声音>` 标签 |
| prompt | 摘要 + 完整提示词文件路径 |
| **预计真实积分** | 按本机实测单价：2.5 480p≈12 分/秒、720p≈20 分/秒；例 20s 480p = **240 分**（不用网上估值） |
| 当前余额 → 预计余额 | 例：7,800 → 7,560 |
| 跑后实际扣分 | 提交后回报：余额差 + `credit_count`（与预计不一致要说明） |
| 产出路径 | `即梦产物/无归原_测试/xxx.mp4` |
| 失败/重跑 | 失败不扣分；成功扣费；重跑需再次确认 |

## 第二次确认：最终执行确认

复述关键项，提醒扣费与风险，并问「最终确认执行吗？」：

> 即将提交：`seedance2.5 / 480p / 16:9 / 20s`，参考图 N 张，**预计真实扣费 240 分**（实测 12 分/秒），余额 `7,800 → 7,560`；生成约 16 分钟，失败不扣费、成功即扣。跑完我会回报**实际扣分（余额差 + credit_count）**。**最终确认执行吗？**

## 执行后动作

- 记录 `credit_count`、**实际余额差（真实扣分）**、submit_id、产物路径；与预计不一致时说明原因；
- ffmpeg 抽帧自审（构图/人数/锚点/穿模/无字幕）；
- 视频卡上画布（`工具/canvas_link_images.py` 或手工卡）并连线；
- 台账、测试记录、项目记忆同步；
- 若失败：记录原因，经用户同意后再重跑，不自动连刷。
