# 逐帧替换提示词 · 总览

> 单帧详细提示词在 `提示词/T1_*.md` … `提示词/T5_*.md`，本文件是索引与统一写法。
> 所有提示词都以「源帧」（`关键帧_源/`）+「目标人物参考」（`素材/目标人物/`）为输入。

## 0. 统一提示词骨架（每帧都套这个结构）

```
【任务】把参考图 1（源关键帧）中的人物替换为参考图 2..N（目标人物），保持其余一切不变。
【人物】保留参考图 2 的脸型、五官比例、发型与发色、体型特征；按原镜头角色服装与姿态重绘。
【风格】2D 赛璐璐动画风格，平涂色块、清晰黑色线稿（线宽与原图一致）、硬边阴影，无照片质感。
【构图】严格保持原图构图、机位、人物位置与比例、背景与光位；不新增、不删除画面元素。
【保留】原字幕位置与内容、原水印位置不动（如有覆盖，按"先擦后贴"另行处理）。
【禁止】新增人物/文字/logo；改变服装设定；真人照片质感；多余手指；变形；重新构图。
```

## 2. 建议生成参数（即梦 CLI · image2image）

```powershell
C:\Users\Administrator\bin\dreamina.exe image2image `
  --images "<源帧.png>" "<目标人物参考1.png>" "<目标人物参考2.png>" `
  --prompt "<该帧提示词>" `
  --model_version 5.0 --resolution_type 2k --ratio 16:9 --generate_num 2 --poll 120
```

- 每帧先生成 2 张挑 1 张；只换女主时参考图给「源帧 + 目标人物 2–3 张」
- 同时换两人时，参考图顺序：源帧 → 目标人物（女主位）→ 目标人物（男主位，如与女主同一人也照样给）
- 分辨率：2k 够（原帧 1080p，2k 出图后缩回 1920×1080 更稳）
- **本轮不执行**，命令见 `08_执行清单_待跑.md`

## 3. 批量一致性

- 先做 T4（侧脸特写）→ 用它作为后续帧的"风格/脸部锚点"之一（image2image 可一次给 10 张参考）
- 每做完一帧，把该帧作为下一帧的参考图之一，可显著减少脸型漂移
- 同一个人的发色/发型在 5 张里必须完全一致，不允许每张"随机一点点"
