# 渲染与清理规范（Blender / 抽帧 / 缩略图）

> 目的：避免渲染中间帧塞进画布项目目录，导致画布监听、缩略图、CPU 全部被拖满。

## 1. 目录规矩

| 用途 | 目录 | 是否在画布扫描范围内 |
|---|---|---|
| Blender 渲染帧 | `<渲染临时目录>\<任务名>\` | ❌ 不在（画布 ROOT 是 `ptest\ptest`） |
| 抽帧/分析临时帧 | `%TEMP%` 或 `<渲染临时目录>\_frames\` | ❌ 不在 |
| 最终成片 | `人物替换_NIGHTDANCER\成片\*.mp4` | ✅ 在（只放成品） |
| 成片帧/底图 | `成片帧_替换`、`关键帧_替换_v7`、`底图_840` 等 | ✅ 在（只放交付用图） |
| 缩略图 | `_canvas/thumbs`（按需生成） | 已被监听忽略 |

**规则：Blender 渲染输出不要再写进 `ptest\ptest` 里的任何子目录。**

## 2. 标准流程

```
1) Blender 渲染 → <渲染临时目录>\<任务>\f_%04d.png
2) ffmpeg 合成 mp4 → 人物替换_NIGHTDANCER\成片\xxx.mp4
3) 合成成功后立即删除 _blender_out\<任务> 整个目录
4) 抽帧尽量用 `ffmpeg -ss` 直接取帧，不要整片抽帧保存
```

## 3. 服务端已做的保护

- 启动时**不再全量扫描缩略图**（8673 张会吃满 CPU），改为 `/thumb` 按需生成
- 文件监听忽略：`_canvas/thumbs`、`_canvas/data/_spec`、`_blender_out`、`成片/blender*`
- 缩略图调度 15 秒节流 + 互斥，不会并发扫盘
- 即梦进度轮询默认关闭（手动点「生成进度」才开）
- 「同步：N 张图」提示 15 秒节流

## 5. 检查命令

```powershell
# 项目内图片数（应只有素材/交付图，几百张）
(Get-ChildItem '<画布根>' -Recurse -File -Include *.png,*.jpg | Measure-Object).Count
# 渲染临时目录（应为空或已被清）
Get-ChildItem '<渲染临时目录>' -ErrorAction SilentlyContinue
```
