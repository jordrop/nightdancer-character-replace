# 视频生成流程总纲（2026-10-18 版）

> 本文把「原片 → 人物替换 → 运镜还原 → 成片」的完整链路固化为可复用的生产流程。
> 适用：把任意 2D MV / 短视频里的人物换成指定角色，保留原构图、原运镜、原音轨。

---

## 0. 一句话流程

```
原片 → 拆镜取帧 → 测运镜 → 去字/底图 → 生图替换（整帧或局部）
     → 画布选图保存 → 同步+导出 → Blender GPU 并发运镜渲染 → ffmpeg 精确合成 → 抽帧自审 → 清理
```

---

## 1. 阶段总览

| # | 阶段 | 输入 | 输出 | 工具/脚本 | 验收 |
|---|---|---|---|---|---|
| 1 | 拆镜 | 原片 mp4 | `分析/镜头分组.json`（K01…K11 起止） | ffmpeg + 场景切分 | 帧数=Σ时长×30 |
| 2 | 取代表帧 | 各镜中段 | `关键帧_源_全部/K##.png` | ffmpeg `-ss -frames:v 1 -update 1` | 无字幕遮挡主体 |
| 3 | 测运镜 | 逐镜帧差 | `分析/运镜位移.json` + 运镜表 | 相位相关（numpy） | 方向与人工看片一致 |
| 4 | 去字/底图 | 代表帧 | `底图_840/K##_base.png`（1920×840） | 裁切（**不拉伸**） | 无重叠副本、无字幕 |
| 5 | 生图替换 | 源帧+角色参考+提示词 | `关键帧_替换_全部/K##_时间_vN.png` | 即梦 CLI `image2image` | 角色一致、构图锁定 |
| 6 | 画布选图 | 各版本 | 画布 `out:K##` 卡 `src/locked/motion` | canvas.html + `/api/board/card` | 点击保存后刷新仍在 |
| 7 | 同步导出 | 画布选择 | `关键帧_替换_v7/K##_v7.png`、`成片帧_画布选定/` | `工具/sync_board_selection.py`、`工具/export_board_frames.py` | 报告显示 changed 镜头清单 |
| 8 | 运镜渲染 | 替换图 + 运镜表 | `_blender_out/render_job/K##/f_####.png` | `工具/render_pipeline.py`（3 路并发 Blender GPU） | 每镜帧数对齐、无黑边 |
| 9 | 合成 | 渲染帧 + 静帧 + 原音轨 | `成片/一键渲染_全运镜_1080p.mp4` | ffmpeg concat | 时长=86.0s、1920×1080、原音轨 |
| 10 | 自审 | 成片 | `分析/*_审核.jpg`（12 帧拼图） | ffmpeg tile | 运镜方向/人物/字幕正确 |
| 11 | 清理 | 渲染帧 | 删除 `_blender_out` 帧 | 流水线自动 | 项目目录不膨胀 |

## 2. 每阶段要点

### 2.1 拆镜 & 取帧
- 按场景切换切镜，记录 `start/end`（秒），不要用整数秒硬猜。
- 提取单帧必须加 `-update 1`，否则 ffmpeg 报错或覆盖异常。
- 不要往 `%TEMP%` 写产物（沙箱可能 Permission denied），写到项目内专用目录。

### 2.2 测运镜
- 用逐帧相位相关（`numpy` FFT）算全局位移，得到每镜总位移像素。
- 输出两个东西：`运镜位移.json`（机器）+ **画布运镜表**（人看）。
- **运镜表是生产的正式输入**，渲染参数（轴/方向/像素）都从它来。

### 2.3 去字/底图
- 字幕带一律**裁切**，禁止拉伸填补（会出"画面重叠副本"）。
- 1920×1080 原片裁到 1920×840 可去掉底部字幕；长图拼接时同样排除字幕带。

### 2.4 生图替换
- 两种模式：
  - **整帧重绘**：`image2image` 给「源帧 + 角色三视图 + 提示词」，适合大改。
  - **局部包围盒替换**：只生成人物区域再贴回，包围盒外像素 `diff=0`，背景零漂移。
- Q 版角色必须写死比例：「头身比 3–3.5、同框身高约为成年男性 1/2–2/3」。
- 即梦 CLI 参数：`--images=a,b,c --model_version=5.0 --resolution_type=2k --ratio=16:9 --generate_num=1 --poll=600`；非 16:9 用 `--width/--height`（不能与 `--ratio` 同用）。
- 队列限流时（返回 `fail`/`querying`）不要连续重试，会白烧积分。

### 2.5 画布选图（人工决策点）
- 每镜一张 `out:K##` 卡，用版本下拉挑图 → **自动写单卡并 `locked`**。
- 点 💾 保存 = 整板保存（`_by:'user-save'`，豁免引用率校验）+ 逐张单卡双写。
- 自动接线已禁用：文件变动**不会**覆盖用户选择。

### 2.6 同步 + 导出（渲染前必跑）
```powershell
python 工具\sync_board_selection.py    # 画布选择 → 关键帧_替换_v7/，md5 报告 changed
python 工具\export_board_frames.py     # 画布选择 → 成片帧_画布选定/ + manifest.json
```
> 漏了这步就会出现"我选了图但成片还是旧的"——这是踩过的真实坑。

### 2.7 Blender GPU 运镜渲染
- 原理：正交相机 + 图片平面（按原图比例），相机平移 = 画面相对运动。
- 引擎：**EEVEE（GPU）**；1080Ti 实测 ≈0.28–0.32 秒/帧；Cycles GPU 约 5.9 秒/帧（不用）。
- 并发：**3 路 Blender 进程**最优；8 镜 2370 帧 374.9s（串行 767s）。
- 平面尺寸必须 `img_h = 1.92 * H/W`，否则 16:9 素材会被压扁。
- 输出统一到 `E:\伊雪的活\_blender_out\`（**画布目录之外**，避免缩略图/监听拖死 CPU）。

运镜参数表（当前项目）：

| 镜 | 方向 | 轴/符号 | 行程 |
|---|---|---|---|
| K01 | 从上往下 | y / + | 380px |
| K02 | 从右往左 | x / − | 180px |
| K03 | 不动 | — | 静帧 |
| K04 | 从上往下 | y / + | 180px |
| K05 | 从左往右 | x / + | 180px |
| K06 | 从下往上 | y / − | 180px |
| K07 | 从左往右 | x / + | 180px |
| K08 | 从右往左 | x / − | 180px |
| K09 | 不动 | — | 原片为 3 图动作（待做） |
| K10 | 从左往右 | x / + | 180px |
| K11 | 不动 | — | 静帧 |

### 2.8 合成
- 每镜按 `镜头分组.json` 精确帧数（`round(时长×30)`）+ `trim/setpts` + `concat`。
- 静帧走 `scale=1920:1080:force_original_aspect_ratio=increase,crop=1920:1080`（不拉伸）。
- 音轨用**原片**：`-map <idx>:a:0 -c:a aac -b:a 192k -shortest`。
- 最终参数：1920×1080 / 30fps / 86.0s / CRF 18。

### 2.9 自审
- 抽 12 帧拼图（`fps=1/7 tile=4x3`）看整体。
- 另抽每个运镜镜头的**首尾帧**对比，确认方向（首帧→尾帧位移方向）。
- 检查：人脸是否丢失、有无黑边、有无重复副本、字幕是否残留。

### 2.10 清理
- 渲染帧合成成功即删；若要保留调试，最多留 24h。
- 画布卡引用的文件被删之前，**同一轮把对应卡也删掉**，避免"文件找不到"占位。

## 5. 质量验收清单（出片前逐项打勾）

- [ ] 每镜 `out:K##` 的选择已保存且刷新不变
- [ ] `sync_board_selection.py` 无意外 `changed`（或 changed 已重渲）
- [ ] 渲染帧数 = 镜头时长 ×30，无缺帧
- [ ] 运镜方向与运镜表一致（首尾帧比对）
- [ ] 1920×1080，无黑边/拉伸/重叠副本
- [ ] 原音轨完整，时长 = 86.0s（±0.1s）
- [ ] 字幕/水印已去掉（或按需求保留）
- [ ] 渲染帧已清理，画布无失效引用

## 6. 已知坑（按出现频率排序）

| 坑 | 后果 | 解法 |
|---|---|---|
| 画布换图后没重渲 | 成片仍用旧图 | 渲染前跑 `sync_board_selection.py`，看 changed |
| 渲染帧删太早 | 改一镜要整批重渲 | 保留帧到成片确认；或只重渲变化镜头再拼旧片 |
| 平面尺寸写死 0.84 | 16:9 素材被压扁 | `img_h = 1.92 * H/W` |
| 拉伸填补字幕带 | 画面出现重叠副本 | 裁切，不拉伸 |
| 自动接线后台覆盖 | 用户选择丢失 | 已禁用自动触发 + `locked` |
| 整板保存被拒/旧数据覆盖 | 保存无效 | `user-save` 豁免 + 单卡双写 + 保存前合并服务端锁定卡 |
| 渲染帧写进项目目录 | 浏览/缩略图把 CPU 拖满 | 输出 `_blender_out`，用完删 |
| 删文件不清画布卡 | "N 个节点文件找不到" | 删文件同轮删卡 |
