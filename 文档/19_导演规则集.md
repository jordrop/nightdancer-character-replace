## 1. 十二模块速查

| # | 模块 | 核心规则 | 本片怎么用 |
|---|---|---|---|
| 1 | 主镜与衔接镜 | 主镜五标准：交代空间关系/建立地理坐标/景别不可随意替换/克制固定或轻微呼吸/拍清"谁在哪、面向哪、视线关系"；衔接镜七功能：反应/插入/环境/反打/补拍/重建/推进 | 每幕先定"主镜"（U01 航拍、U17 无归原全景、U24 篝火中景、U32 归途大远景），其余按七功能归类 |
| 2 | 正反打 | 五常规机位：正面特写（注视点偏 15°）/过肩/45°近景/双人中景/全景；两特殊：越轴反打（只能一次）、主观镜头反打 | 本片无对白：把"正反打"改成**人物关系镜**——救人与被救、看与被看；越轴只留给雪崩/雾中巨影的情绪爆点 |
| 3 | 轴线与空间 | I 型（两人连线）/L 型（随视线）；四种换轴：人物运动/主镜重建/空镜/视线切换 | 群像最多 5 人，必须先用主镜（U01/U17）立坐标；人物移动后换轴要补一个全景或空镜 |
| 4 | 景别节奏 | 渐紧渐松（全→中→近→特）；反拉抽屉（特写过多时插入全景）；插入镜必须短于/等于前后镜头 | 15s 单元内：大远景起 → 中景 → 近景/特写；情绪峰值后插一个全景"喘气" |
| 5 | 构图与视角 | 招式型（动作主导）/层次型（前景-中景-后景）/主观/客观 | 雪崩用招式型，无归原用层次型（枯草前景+泥沼中景+雾后景），陷泥用主观 |
| 6 | 视觉焦点与动势 | 横向优先/同向顺滑/反向冲突 | 队伍横向行进用横移；雪崩从右向左 vs 人往右逃 = 反向冲突 |
| 7 | 运镜 | 五作用：推近/拉远/横移/摇镜/环绕；插入镜五标准；摇镜必须有动机、速度匹配情绪、起落稳；拉镜必须有叙事目的 | 推近=压迫（U04/U22），拉远=疏离/收尾（U16/U32），横移=跟队伍（U05/U23） |
| 8 | 关系/群像十检 | 谁说话/谁在听/视线关系/空间位置/人物出场锚点/辨识度/动作节拍/同框距离/声画同步/调度方向 | 用 C1–C4 的锚点（围巾/皮帽/裂镜/红绳铜铃）保证辨识度；阿荞是主要"反应镜"承载者 |
| 9 | 分镜诊断九病 | 跳轴/单调/无反应/乱插/抽帧/死盯/切头/僵硬/疏离 | 出图/出片后按九病逐条体检，尤其"无反应病""乱插病"（AI 容易生成无功能空镜） |
| 10 | 反应镜头优先 | 一场戏节奏由反应驱动，不由台词量驱动 | 本片无对白：**反应镜头 = 情绪锚点**（阿荞看雪山/看火/看雾），优先于"动作大全景" |
| 11 | 运镜克制等级 L0–L3 | L0 完全固定（主镜/插入/动作特写）；L1 0.05–0.1cm/1–2Hz（对话/近景）；L2 0.1–0.15cm/2–3Hz（情绪爆发/极近景）；L3 0.15–0.2cm/3–5Hz（主观/追逐） | 直接映射到 Seedance prompt："固定/轻微呼吸/轻微手持/手持跟拍"；L0 镜头不加"晃动"字样 |
| 12 | 红线 | 无动机推拉/同景别连续 3 镜以上/跳两级景别/越轴后同侧继续/无功能空镜/无反应镜/前景遮挡冒充过肩/硬塞前景/只拍嘴 | 全部转成生成负面约束（见 §3） |

## 2. 与现有体系的接口

| 体系 | 关系 |
|---|---|
| **V1000 四段式**（`文档/16` §9） | 导演规则决定"拍什么/怎么切"，V1000 决定"光照参数/节奏/音效"措辞；两者拼成完整提示词 |
| **镜头参数 schema**（`工具/镜头参数.schema.json`） | `camera.mode/axis/px` 是执行层；导演规则是它的**语义层**（主镜/衔接/反应/插入/环境） |
| **无归原时间线**（32×15s） | 每幕先标主镜，其余标衔接功能；15s 内部按景别节奏切 2–6 点 |
| **关键帧/视频验收** | 除原有验收（人数/锚点/穿模/文字）外，加"导演九病"检查 |

建议：下次改时间线时给每个单元加 `director: {role: 主镜|反应|插入|环境|反打|推进, shot_scale, move_level: L0-L3, axis_note}`，不改变现有字段。

## 3. 提示词片段模板（可直接拼进 V1000 四段式）

```text
【主镜】固定机位/轻微呼吸，大远景建立空间：A 在左、B 在右、相距约 X 米，A 面向 B；不推拉。
【反应镜】特写/近景拍听者反应：C 的眼神/手指/呼吸变化，不拍说话者。
【插入镜】特写道具：铜铃/红绳/火种罐，时长 1–2s，只给局部，不重复前镜信息。
【环境镜】空镜：雪脊/枯草/低雾，3–4s，无人物，仅交代空间与天气。
【主观镜】POV：镜头代角色眼睛，呼吸晃动 L3，前景泥水/雪粒模糊。
【越轴】仅一次：切到轴线另一侧，配合音乐重音/雪崩/巨影出现。
```

### 运镜措辞对照（避免 AI 乱晃）

| 等级 | 提示词写法 | 不要写 |
|---|---|---|
| L0 | 固定机位、三脚架、画面稳定 | 轻微晃动/呼吸感 |
| L1 | 极轻微呼吸感、固定为主 | 手持/跟拍 |
| L2 | 轻微手持、缓慢推近 | 快速甩镜 |
| L3 | 手持跟拍、呼吸急促、主观晃动 | 固定机位 |

## 4. 生成前/后自检清单

**生成前（分镜层）**
- [ ] 这场有主镜吗？主镜是否建立"谁在哪、面向哪、和谁有视线关系"？
- [ ] 每个衔接镜能归到七功能之一吗？（反应/插入/环境/反打/补拍/重建/推进）
- [ ] 反应镜头是否优先于"动作大全景"？
- [ ] 景别是否渐紧/渐松？是否连续 3 个以上同景别？是否跳两级？
- [ ] 运镜有动机吗？幅度等级（L0–L3）与情绪匹配吗？
- [ ] 轴线是否被无理由打破？换轴是否用"人物运动/主镜/空镜/视线"四种方法之一？
- [ ] 插入镜是否短于或等于前后镜头？是否重复已有信息？

**生成后（画面层）**
- [ ] 九病排查：跳轴/单调/无反应/乱插/抽帧/死盯/切头/僵硬/疏离
- [ ] 群像十检：视线、位置、辨识度、动作节拍、同框距离、调度方向
- [ ] 前景遮挡是否被误当过肩？是否有硬塞前景？
- [ ] 人物头部/手指是否被切？是否穿模？
- [ ] 无文字/无 logo/无字幕（项目铁律）

**红线（直接转成负面约束）**
> 无动机推拉摇移；同一场景连续 3 个以上同景别；切镜跳两级景别；越轴后用同侧机位；无功能空镜；对话/关系戏无反应镜头；前景遮挡冒充过肩；为"高级"硬塞前景；长时间只拍说话者的嘴。
