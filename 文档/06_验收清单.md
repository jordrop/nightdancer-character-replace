# 验收清单（每张替换帧逐项过）

## 1. 硬性（不过 = 重做）

| # | 检查项 | 判断方法 |
|---|---|---|
| 1 | **身份**：像不像目标人物 | 与参考图并排看；发色/发型/脸型/五官比例能对上 |
| 2 | **构图**：与原帧一致 | 叠图对比：背景线（货架横线/地平线/门框）位置偏差 ≤ 2% |
| 3 | **人物数量**：不增不减 | 原帧两人就两人；背景不许冒出第三个人影 |
| 4 | **无变形** | 手指 5 根、烟在手指间、肢体不穿插、不融进背景 |
| 5 | **画风** | 2D 平涂 + 线稿 + 硬边阴影；无照片质感、无 AI 塑料皮肤 |
| 6 | **光位** | 与原帧光源方向一致（S05 顶光偏暖、S08 冷蓝轮廓光、S06 月光左上） |
| 7 | **字幕/水印** | 三行字幕位置、内容、字体未被改动；水印未被拉伸/重绘 |
| 8 | **服装设定** | 与镜头一致（超市制服 / 黑夹克 / 西装），不是自由发挥 |

## 2. 软性（影响观感，尽量过）

- [ ] 眼神方向与原帧一致（S05 视线向下/闭眼、S08 侧视远处）
- [ ] 表情与原帧情绪一致（叹气、叼烟、发呆）
- [ ] 头发/衣物的边缘有原画的硬边阴影，不是软糊渐变
- [ ] 烟雾、反光、雨/夜色的氛围没被"清理"掉
- [ ] 同一人物跨 5 帧放到一起看，像同一个人

## 3. 五张的专项验收点

| 帧 | 专项 |
|---|---|
| T1（超市·S03） | 梯子位置、怀里报纸的折角、红篮子、仰视透视；男主背影廓形不变 |
| T2（办公室·S05） | 撑头的手与脸的遮挡关系、桌沿透视、暖光方向；不要把手画成"贴脸" |
| T3（夜巷·S06） | 月亮位置、竹篱笆横线、烟雾形状；剪影只改轮廓不改脸 |
| T4（侧脸·S08） | 侧脸轮廓线、叼烟角度、黑夹克领口；这是最容易"换脸失败"的一张 |
| T5（字卡·S10） | 全身比例、两人站位间距、白色背景边框；字幕「2人別々」区不动 |
