# 替换规则与边界

## 1. 改什么 / 不改什么

| 层 | 处理 |
|---|---|
| 人物身份（脸、发型发色、体型） | ✅ **要改**（替换成目标人物） |
| 人物服装 | ⚠️ 按原镜头对应（超市制服 / 私服两套），不凭空换装 |
| 动作 / 姿态 / 视线 | ❌ 不改（保持原帧的姿势与构图） |
| 背景（货架、街道、月亮、竹篱笆） | ❌ 不改 |
| 光位 / 色调 / 氛围 | ❌ 不改（S05 暖橙、S08 蓝调、S06 月光） |
| 字幕（三行烧录） | ❌ 不改文案、不改位置（策略见下） |
| 上传者水印 + bilibili logo | ❌ 不主动移除；如影响观感，只做「不影响人物的弱化」并在验收时标注 |
| 画风（2D 赛璐璐、线稿、硬阴影） | ❌ 不改；目标人物必须"动漫化"进画面（路线 A） |

## 2. 字幕与水印策略（烧录层）

三行字幕与左上角水印是**烧死在画面里**的，替换人物时有三条路，按成本从低到高：

1. **保留策略（默认，最省）**：只替换人物区域，字幕/水印区域当作"不可改层"原样保留。
   - 要求：替换区域不压到字幕行（字在底部居中，人物多在画面上半/中部，通常不冲突）
   - 优点：0 额外工作；缺点：人物与字幕若有交叠（如 S03 梯子上的脚、S07 腿部）需要局部修
2. **先擦后贴（推荐给交付版）**：先用同一张图把字幕/水印区域做"无字版"（inpaint 或按背景延展），
   替换完人物后再把原字幕层以原位置回贴（保留原字体、原字号、原描边）。
   - 好处：人物怎么改都不压字；坏处：多一轮修复
3. **重排版（成本最高，仅必要帧）**：字幕改成可编辑层，最后统一渲染。
   - 只有当你要求「中文字幕也要换」时才需要

> 本轮方案：**默认走策略 1**；如你要求成片级观感，再对 1–2 帧升级到策略 2。

## 3. 2D 画风的硬约束

- 平涂色块 + 清晰线稿 + 硬边阴影；**不允许**出现照片质感、真实皮肤纹理、景深虚化。
- 目标人物的"动漫化"要点：保留**可辨认的脸型/五官比例/发型轮廓**，把皮肤、光影、发丝简化为 2D 画法。
- 线宽与原画面一致（约 2–3 px）；阴影边缘硬，不用渐变雾化。
- 烟雾、光线（S06 月光、S08 轮廓光）要**沿用原帧**，只在与人物相交处重画。

## 4. 禁止项

- 不新增画面元素（新道具、新人物、新文字、新 logo）
- 不改变人物数量（原帧两个人就还是两个人）
- 不移动构图（不重新构图、不裁切、不放大主体）
- 不改变场景时间（如把夜景做亮）
- 不用真人照片直接覆盖（否则违背 2D 一致性；若你选路线 B 则另立方案）
