# 一致性控制（锁脸 / 锁风格 / 锁角色）

## 1. 三个人物锚点

替换不是"每帧自由发挥"，需要先把目标人物固定成一个可复用的锚点：

| 锚点 | 内容 | 来源 |
|---|---|---|
| 锚点 A · 正脸 | 正脸、平视、中性表情 | 目标人物参考图 |
| 锚点 B · 侧 3/4 | 左/右侧 3/4 | 目标人物参考图 |
| 锚点 C · 半身/全身 | 站姿、服装轮廓 | 目标人物参考图 |

> 三张锚点图 + 当前源帧 = image2image 的参考图（最多 10 张，够用）。

## 2. 跨帧一致性清单

每生成一张，对照检查：

- [ ] 发色、发长、刘海分缝、马尾高低（女主原设是低马尾，替换时保留该发型轮廓）
- [ ] 脸型（长宽比）、下颌线、眼型、眼距、眉形、鼻梁高度、唇形
- [ ] 体型（肩宽、身高比例）与原镜头人物一致
- [ ] 服装按本镜头设定：S03 超市制服 / S05 办公室（私服或制服待定）/ S08 黑夹克 / S10 西装 + 黑夹克
- [ ] 色调：S05 暖橙、S06 蓝绿月光、S08 蓝调冷光，不许统一成一种色
- [ ] 线稿粗细、阴影硬边、涂色颗粒感与原画面一致
- [ ] 表情与原帧一致（S05 是"叹气/无奈"，不是微笑；S08 是"叼烟侧视"）

## 3. 防"换脸漂移"的做法（按有效性排序）

1. **锚点图 + 当前帧** 一起送 image2image（首选）
2. 上一张成功结果作为下一张参考（链式传递）
3. 提示词里显式写"与参考图 2 为同一人"，并写死发型/发色/脸型关键词
4. 出图后用同一裁剪比例对照原帧（并排对比）人工挑
5. 仍漂移时：降低 generate_num、提高 prompt 权重描述、或先做 1 张"标准像"再派生

## 4. 一致性风险点

- **S10 是全身**：小脸尺寸下最容易"看不出是谁"，需要靠发型/体型/服装保证辨识
- **S06 是剪影**：不要尝试画脸，改成"轮廓 + 体态"一致即可
- **S03 两人同框**：如果两人都换，注意不要在背景里出现第三个人影（模型容易补人）
- **字幕区**：替换时若人物压到字幕，先不动字幕，出图后在验收时标"需擦贴"
